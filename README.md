# Nemocnice Pardubického kraje redesign

Tato verze je záměrně zcela jiná než předchozí NPK návrhy i DPMP.

Designový směr:

- velký fotografický vstup podobného kvalitativního standardu jako moderní nemocniční weby,
  ale bez kopírování konkrétního layoutu FN HK,
- split hero: vlevo identita NPK, vpravo fotografie reálného prostředí nemocnice,
- vyhledání pracoviště/lékaře je funkční vrstva přes spodní část hero,
- klíčové pacientské úlohy nejsou kartičkový dashboard,
- nemocnice jsou řešené jako číslovaný seznam,
- pacientská sekce používá fotografii + velký obsahový blok,
- orientace v areálech má vlastní horizontální sekci,
- aktuality mají jeden výrazný redakční článek a textový seznam,
- kariéra je samostatná fotografická sekce,
- žádné generické marketingové slogany, KPI, pill badges, gradientové dekorace nebo „AI“ helper texty.

Použité fotografie jsou odkazy na veřejné obrázky z webů NPK:

- nový pavilon Pardubické nemocnice,
- fotografie z NPK slideru,
- kariérní fotografie NPK.

Použito:

- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Open Sans
- vanilla JavaScript
